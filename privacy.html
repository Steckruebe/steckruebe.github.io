Datenschutzerklärung – Hermes Gmail

Hermes Gmail ist eine private Anwendung von Jens Klett. Einziger Nutzer ist Jens Klett selbst.

Welche Daten

Die Anwendung nutzt ausschliesslich die Berechtigung gmail.readonly. Sie kann E-Mails lesen, aber nicht senden, löschen, verschieben oder verändern.

Verwendung

E-Mails werden nur auf Anfrage des Nutzers abgerufen, um sie für ihn zu lesen, zu durchsuchen oder zusammenzufassen. Dazu wird der Inhalt abgerufener E-Mails an den KI-Dienst Anthropic (Claude) übermittelt, der den persönlichen Assistenten betreibt. Es findet keine Weitergabe an andere Dritte, keine Werbung und kein Verkauf von Daten statt.

Speicherung

Der Zugriffstoken wird geschützt auf einem privaten Server des Nutzers gespeichert. Das Postfach wird nicht vollständig kopiert.

Widerruf

Der Zugriff kann jederzeit unter myaccount.google.com/permissions entzogen werden.

Die Nutzung der über Google-APIs erhaltenen Daten hält sich an die Google API Services User Data Policy, einschliesslich der Anforderungen zur eingeschränkten Nutzung (Limited Use).
